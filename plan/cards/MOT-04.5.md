This card produces the MOT-04 deliverable. Everything runs against the mock stack. The sweep is IK/FK-query only, so nothing moves.

Steps:
1. `bash scripts/ros/build_ws.sh`.
2. Full sweep. Run it in the background and watch the progress log:
   `bash scripts/ros/run_reachability.sh --reachability-config config/motion/reachability.yaml --out data/motion/reachability_map.json --max-duration-s 2400`
   The expected upper bound is roughly 7k targets, fewer after prefiltering, at about 10–160 ms each, i.e. well under 40 min.
   If it would not finish (complete:false), coarsen only the grid step, to 0.03 at most, or trim clearly unreachable x/y extents in config/motion/reachability.yaml. Do not change orientation, IK tolerance or collision settings. Record the change and the reason in the doc, then re-run. Leave the map in data/motion/ (git-ignored; do not commit it) and record its sha256.
3. `ros2 run crackvision_motion recommend_placement --map data/motion/reachability_map.json --out config/motion/specimen_placement.yaml --emit-verify-config config/motion/placement_verify.yaml` (inside env_ros.sh + overlay). Exit 1 (infeasible) is a legitimate result. In that case write the doc honestly and stop. Do not shrink the footprint or tolerance to manufacture feasibility.
4. Independent verification: run the `placement-verify` acceptance command yourself and record the result.
5. `scripts/motion/plot_reachability.py`:
   - Runs in the conda env (`./env.sh python`) with matplotlib 3.11. Set MPLCONFIGDIR to a writable dir under logs/ because ~/.config is read-only.
   - Follows §0: the common flags via crackvision.config.add_common_args, and logs via crackvision.logging_setup.
   - Reads the map JSON directly with json. It must not import the ROS-side modules.
   - Flags: `--map` (default data/motion/reachability_map.json), `--placement` (optional), `--out` (default docs/motion/figures/reachability.png).
   - One figure with one panel per surface_z. Each cell's colour is the fraction of standoffs reachable, and the reachable cells' min joint margin is shown with a separate symbol or contour. Draw the base_link origin, the recommended footprint + tolerance outline, and the alternatives. Label the axes in m in base_link.
   - Use ≤ 150 dpi so the PNG stays ≤ 400 KB.
   - `--dry-run` validates its inputs and writes nothing.
6. `docs/motion/REACHABILITY.md` sections:
   - Purpose.
   - Method: MoveIt compute_ik with trac_ik; boresight-down with roll sampling; standoffs; surface slab; FK re-check; prefilter bound.
   - Commands.
   - Results: table per surface_z; the figure; the recommended placement and alternatives.
   - Independent verification result.
   - Comparison with TECHNICAL_APPROACH §2.5. Note that the presentation's tool frame was gripper_link, 44.3 mm behind gripper_tcp; it used a custom DLS IK with 5-DOF constraint and no collision checking; its coupon surface was at z=0.12. Check the map near (0.22, 0) and (0.42, 0) at the closest surface_z and report what it says.
   - Caveats + re-run triggers: GEOM-03, GEOM-07, MOT-03, MOT-10, and any change to config/robot/b601_dm_limits.yaml.
   - Handoff to MOT-10/MOT-03: the placement YAML is the pose the operator targets; MOT-10's measurement supersedes it. If config/scene/** from MOT-03 exists by then, state how the specimen object there should take its nominal pose from this file, and match MOT-03's measured|nominal tagging vocabulary in the YAML header comment.

Commit only the files in scope. Never commit data/ or logs/.
