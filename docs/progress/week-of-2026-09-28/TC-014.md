## What was done

Added the integration and contract test suite for the crack-vision pipeline (TC-014): it runs the real prepare-inputs to visualize to skeleton chain end-to-end on synthetic images (including a non-square one to catch transpose bugs), checks that every generated file keeps the same width and height as the original, validates the on-disk JSON schemas (case map, skeleton stats, camera metadata, run logs), and scans the codebase for hard-coded file paths and other forbidden patterns. The full test suite passes with 205 tests passing and 3 correctly skipped (no GPU/camera on this machine), and the no-GPU/no-camera/no-model filtered run also passes cleanly - no bugs were found in the existing pipeline code.
