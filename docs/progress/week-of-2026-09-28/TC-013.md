## What was done

The D405 camera capture tool (crackvision.realsense_capture) now works end-to-end in synthetic mode with no camera attached: it writes aligned color/depth PNGs plus full intrinsics/extrinsics metadata JSON matching the project's documented schema, and correctly exits with code 3 and an actionable message when no camera is present. I found and fixed a crash bug that broke every capture attempt, added a dedicated test file covering the synthetic file outputs and schema, and the full test suite (91 tests) passes with no regressions. Actual camera hardware testing remains deferred since no D405 is connected to this machine, as expected for this stage of the project.</presentation_summary>
