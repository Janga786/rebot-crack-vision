# TC-015 — Evaluation-manifest tooling

**Accepted:** 2026-09-29 · **Work package:** Perception (L-PERC) · **Track:** software · **Verified commit:** [`8ef6b16`](https://github.com/Janga786/rebot-crack-vision/commit/8ef6b164d2d9697d5a6a29cb0df134812310620f)

## What was done

Built the evaluation-manifest CLI (tools/dataset_manifest.py) that will let us track distance, angle, lighting, surface and crack labels for every D405 evaluation image before any real images are captured. It creates a header-only manifest, auto-fills machine-derived fields (paths, timestamps, depth-validity fraction) from capture metadata without ever overwriting human-entered labels, validates the schema (catching bad enums, duplicate IDs, missing files, out-of-range values), and prints coverage-vs-target shortfalls per evaluation block. 20 new tests plus the full 225-test project suite pass, and no real evaluation imagery was captured or added to the repo.
