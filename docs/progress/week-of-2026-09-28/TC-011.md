## What was done

Built the project's single "run everything" command: ./run_test.sh takes images dropped in data/input_originals/ through environment checks, input prep, GPU/CPU inference, visualization and skeletonization, then prints a summary table (size, crack %, skeleton pixel count, component count, comparison-image path) via a new scripts/summarize_run.py. Verified on this machine (no GPU available) with --device cpu: two synthetic test images ran end-to-end in about 25 seconds with a clean summary table and exit code 0, and an empty-input run correctly stopped with a plain-English message and exit code 3 instead of a stack trace. All 164 pre-existing unit tests still pass.</presentation_summary>
