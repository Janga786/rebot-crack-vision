# TC-004 — OpenCrack model acquisition from Hugging Face

**Task ID:** TC-004 · **Complexity:** SMALL–MEDIUM · **Prerequisites:** TC-001, TC-002

## Objective
Build `scripts/fetch_model.py` to download `fadeevla/opencrack-nnunet` into the project, validate the
file tree, and record a sha256 manifest.

## Why this matters
This is the only external artefact the project depends on. Recording hashes and validating the tree
is what turns a silent upstream change into an early, legible error (`RISKS.md` R-06).

## Prerequisites
- TC-002 COMPLETE (`huggingface_hub` installed in the env)
- Network access. The repo is **public and ungated** — no HF token is needed (none is configured).

## Scope
Implement `scripts/fetch_model.py` per `docs/INTERFACES.md` §3.6 and produce
`config/model_manifest.json`.

## Out of scope
- The `nnunet/results` symlink and the semantic validation of `dataset.json`/`plans.json` — that is
  **TC-005**. This card only verifies the files *exist* with the right sizes.
- Running inference.
- Downloading any other model.

config/model_manifest.json   (generated by running the script)
```
The download itself lands in `models/opencrack-nnunet/` (gitignored).

## Implementation requirements

### Verified upstream facts — do not re-derive

Repo `fadeevla/opencrack-nnunet`, last modified 2026-06-20, `gated: false`, licence **CC-BY-4.0**.
Exact tree:
```
.gitattributes
README.md
reproducibility/splits_final.json
Dataset501_OpenCrack/nnUNetTrainer__nnUNetPlans__2d/dataset.json                   (~700 B)

Dataset501_OpenCrack/nnUNetTrainer__nnUNetPlans__2d/fold_0/checkpoint_ep0500.pth   (268.09 MB)

> ⚠️ The model card's prose mentions "`nnUNetPlans.json`"; the **actual file is `plans.json`**, which
> is what nnU-Net v2 requires. Trust the tree.

### Download

```python
from huggingface_hub import snapshot_download
path = snapshot_download(
    repo_id="fadeevla/opencrack-nnunet",
    local_dir=cfg.models_dir,                     # models/opencrack-nnunet
    allow_patterns=["Dataset501_OpenCrack/**", "README.md", "reproducibility/**"],
)
```

- **Use `local_dir`.** `~/.cache/huggingface` is already 17 GB; do not add another 268 MB copy there.
- `huggingface_hub` is **0.36.x**. Do not pass `local_dir_use_symlinks` — it is deprecated/removed in
  modern versions. If the installed version rejects any kwarg, drop the kwarg (not the call) and note
  it under `ISSUES:`.
- Capture the resolved revision if the API offers it (`HfApi().model_info(repo_id).sha`); if
  unavailable, record `null` — do not fail.

### Validation (exit 3 if any missing)

```
Dataset501_OpenCrack/nnUNetTrainer__nnUNetPlans__2d/plans.json
Dataset501_OpenCrack/nnUNetTrainer__nnUNetPlans__2d/dataset.json
Dataset501_OpenCrack/nnUNetTrainer__nnUNetPlans__2d/fold_0/checkpoint_ep0500.pth
```
The checkpoint must be between 250 MB and 300 MB; outside that range → exit 3 ("download truncated or
upstream changed").

### `config/model_manifest.json`
Schema in `docs/INTERFACES.md` §3.6. Compute sha256 in 1 MB chunks (do not read 268 MB into memory).
Write it atomically (temp file + `os.replace`) so an interrupted run never leaves a half-manifest.

### Flags
- `--repo-id` (default from `config/project.yaml`), `--dest`
- `--force` — re-download even if present
- `--verify-only` — skip download, just validate + re-hash against an existing manifest

Idempotent: a second run with everything present re-verifies and exits 0 **without re-downloading**.

## Failure handling
- **Network failure / timeout** → exit 1 with the underlying error. Do not leave a partial manifest.
  Retry is acceptable; three failed attempts → BLOCKED.
- **Repo gated / 401** → BLOCKED. Report exactly what the API returned. Do **not** add a token.
- **A file in the expected tree is missing upstream** → BLOCKED with the actual listing from
  `HfApi().list_repo_files(repo_id)` pasted into the report. This is `RISKS.md` R-06 and is a real
  finding, not something to work around.
- **`snapshot_download` rejects a kwarg** → drop that kwarg, keep the call, note it.
- **Disk full** → report; delete nothing outside the project.
